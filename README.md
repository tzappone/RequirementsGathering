# System Requirements Gathering
## Description
System requirements were gathered for a group project that built a system for a local non-profit, Pets4Life. The requirements gathered were both functional and non-functional.

# 1.1. A Stripe Donation Requirements
* ID: SR001- The Stripe Donation Module will allow donations to be made.
ID: SR002- The Stripe Donation Module will allow donors to select an amount to donate.
ID: SR003- The Stripe Donation Module will allow donors to make a one-time donation
ID: SR004- The Stripe Donation Module will allow donors to set up a recurring donation.
ID: SR005- The Stripe Donation Module will allow Pets4Life to view donations that are made by users.
ID: SR006- The Stripe Donation Module will allow Pets4Life to access/use donations that are made by users.
ID: SR007 – The Stripe Donation Module will allow Pets4Life to access financial reports 
ID: SR008 – The Stripe Donation Module will allow donors to receive a donation receipt

# 1.1.B Automated Text Messaging Requirements
ID: SR009 – The Automated Text Messaging Module will allow users to opt-in for text messaging
ID: SR010 – The Automated Text Messaging Module will allow users to select the group they identify with
ID: SR011 – The Automated Text Messaging Module will allow Pets4Life to create user groups
ID: SR012 – The Automated Text Messaging Module will allow Pets4Life to craft a message
ID: SR013 – The Automated Text Messaging Module will allow Pets4Life to send messages 
ID: SR014 – The Automated Text Messaging Module will allow Pets4Life to view SMS success rates
ID: SR015 – The Automated Text Messaging Module will allow users to opt-out of text messaging
ID: SR016 – The Automated Text Messaging Module will allow Pets4Life to ensure compliance with text messaging laws

# 1.1.C Event Calendar Requirements
ID: SR017 – The Event Calendar Module will allow Pets4Life to upload new events
ID: SR018 – The Event Calendar Module will allow Pets4Life to delete events
ID: SR019 – The Event Calendar Module will allow users to toggle between the Pet Event Calendar and the Volunteer Event Calendar
ID: SR020- The Event Calendar Module will allow users to view the scheduled events
ID: SR021- The Event Calendar Module will allow users to select an event to attend.
ID: SR022- The Event Calendar Module will allow users to sign up for an event.
ID: SR023 – The Event Calendar Module will allow Pets4Life to view a list of users who have signed up for a given event.
IDSR024 – The Event Calendar Module will allow users to receive confirmation for the event they have signed up for. 

# 1.1.D Chatbot Requirements
ID: SR025 – The Chatbot Module will allow Pets4Life to update the chatbot’s knowledge base
ID: SR026- The Chatbot Module will allow pet owners to ask questions regarding pet care and/or Pets4Life.
ID: SR027- The Chatbot Module will allow pet owners to get instantaneous answers to questions regarding pet care and/or Pets4Life.
ID: SR028- The Chatbot Module will provide pet owners with links to parts of the site relevant to them.
ID: SR029- The Chatbot Module will allow Pets4Life to view the types of questions that pet owners are asking.
ID: SR030 – The Chatbot Module will allow pet owners to leave their phone number if they did not get the response they were looking for
ID: SR031 – The Chatbot Module will allow Pets4Life to view phone numbers left for follow-up

# 1.1.E Pet Owner Testimonies Requirements
ID: SR032 – The Pet Owner Testimonies Module will allow pet owners to write a testimonial
ID: SR033 – The Pet Owner Testimonies Module will allow pet owners to optionally upload a picture along with their testimonial
ID: SR034 – The Pet Owner Testimonies Module will allow pet owners to submit their testimonial 
ID: SR035 – The Pet Owner Testimonies Module will allow Pets4Life to receive an email when a testimony is submitted
ID: SR036 – The Pet Owner Testimonies Module will allow Pets4Life to delete a testimonial 

# 1.1.F Website Statistics Requirements
ID: SR037 – The Website Statistics Module will allow Pets4Life to view engagement data
ID: SR038 – The Website Statistics Module will allow Pets4Life to modify the system as deemed necessary

# 1.1.G Deposit Retainer Requirements
ID: SR039 – The Deposit Retainer Module will allow Pet4Life to set a fixed retainer amount
ID: SR040 – The Deposit Retainer Module will allow pet owners to pay the retainer as an up-front cost  
ID: SR041 – The Deposit Retainer Module will allow pet owners to receive a receipt for the retainer paid

# 1.2           Non-Functional Requirements
ID: SR042 – The content management system will allow for mobile use
ID: SR043 – The content management system will provide user-friendliness 
ID: SR044 – The payment management system will allow for secure payment processing
